# UI Website Hotel

Website hotel yang dibangun menggunakan PHP, HTML, CSS, dan JavaScript.

## About

UI Website Hotel adalah website untuk menampilkan informasi hotel secara profesional dan responsif, meliputi informasi hotel, fasilitas, kamar, dan halaman kontak.

## Features

- Homepage
- About Hotel
- Hotel Facilities
- Room Information
- Contact Page
- Admin Dashboard
- Responsive Design

## Technologies

- PHP
- HTML5
- CSS3
- JavaScript
- MySQL
